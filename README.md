# ⛑️ HelmNet - Safety Helmet Detection System

## 📌 Project Overview
HelmNet is a computer vision project developed as part of the **Introduction to Computer Vision** course.

The objective of this project is to build an automated image analysis system capable of detecting whether workers are wearing safety helmets. The system is designed to help improve workplace safety compliance, reduce risks of head injuries, and minimize human error in safety monitoring.

---

## 🎯 Objectives
- Detect helmet compliance using image classification
- Improve workplace safety monitoring
- Automate safety enforcement processes
- Reduce manual inspection efforts
